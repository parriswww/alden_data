## Generated illustration

`pipeline-illustration.webp` was generated for this project using AI and cropped
to a wide composition. It illustrates typed documents, conceptual validation
gates, and spreadsheet output in Alden's cream, navy, and azure colors.
It is not a screenshot, performance claim, security certification, or evidence
of a live processing system.

## File handling

Full-size generated media and downloaded working originals are kept in the
ignored `generated-artifacts/alden-imagery/` directory. Only the small,
optimized website assets are deployed. Combined served image size is about
150 KB; intrinsic image dimensions are retained for layout stability.
