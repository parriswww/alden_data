# Alden Done for You — GitHub Pages

This is a static HTML/CSS export of the existing Done for You website.
No Node.js, React, API key, build command, or server is needed to host these files.

## Upload to GitHub Pages
1. Create or open your GitHub repository.
2. Unzip the download on your computer.
3. Upload the CONTENTS of the alden-done-for-you folder to the repository root.
   index.html and style.css must be at the top level. Include images/ and legal/.
4. Commit the uploaded files to your main branch.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose main and /(root), then Save.
8. Wait for GitHub's Pages deployment to finish. Open the site link shown there.

Do not upload only the ZIP or only index.html: the stylesheet and images are required.
The relative paths support both username.github.io and username.github.io/repository/.
You can also open index.html locally, without a development server.

## Included
- index.html: Done for You main page.
- pricing.html: Complete existing public pricing, including destination add-ons.
- privacy-policy.html and terms-and-conditions.html: Existing legal pages.
- style.css, local logo/photos/illustration/favicon, and legal PDF downloads.
- .nojekyll: Disables Jekyll processing where applicable.

## Important
- This export does not change or publish the Replit site.
- Subscription, Capabilities, Service Tiers and other non-exported routes link
  to the existing published site at https://aldendatasolutions.replit.app.
- The original page copy, prices and existing external links are preserved.
  The existing WhatsApp link is generic; it does not select a specific business chat.
- Email/contact/cancellation links open the visitor's email app. They do not
  send email, cancel billing, or take payment automatically.
- GitHub Pages does not run Make/Gemini, process documents, provide an inbox,
  or host the Replit backend. Do not put API keys or customer files in this repository.
- Google Fonts requires internet access; system fallback fonts work offline.
- Pricing, availability, cancellation and security wording is preserved from
  the website; this export does not establish live workflow verification.
- Keep the existing stock-photo credits and illustrative-image disclosures.
- For a custom domain, use GitHub Pages' current custom-domain instructions.
  This export does not change DNS or fix existing domain connections.
- Edit HTML/CSS directly in this exported folder, or regenerate from Replit.
  Re-running the exporter replaces the export folder; it does not edit app pages.
